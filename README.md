## Stack

- Next.js (App Router)
- React
- Tailwind CSS
- shadcn/ui
- lucide-react
- canvas-confetti
- sonner

## Design system

- Display font: Georgia (local font via next/font/local)
- Body font: Outfit (Google font)
- Brand palette and tokens are defined in app/globals.css
- Motion: reveal on scroll, subtle hover lift, image tilt on hover, confetti on contact success
